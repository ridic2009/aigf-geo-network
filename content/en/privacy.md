## What we collect

This site is a set of static files. There are no user accounts, no comment
system and no forms. We set no advertising cookies and sell no data.

## Server logs

Our host keeps standard access logs — IP address, user agent, requested URL,
timestamp — for security and troubleshooting. They are kept for a limited period
and are not used to build profiles.

## Outbound links

When you follow a link to a provider, their privacy policy applies from that
point on. Some links carry a campaign parameter so the provider can attribute
the referral.
