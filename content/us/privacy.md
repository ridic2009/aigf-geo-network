## Data we collect

This website is a set of static files. It has no accounts, no comment system and
no forms. We do not set advertising cookies and we do not sell data.

## Server logs

Our hosting provider records standard access logs (IP address, user agent,
requested URL, timestamp) for security and troubleshooting. Logs are retained for
a limited period and are not used to build user profiles.

## Outbound links

When you follow a link to a vendor, that vendor's own privacy policy applies.
Some links carry a campaign parameter so the vendor can attribute the referral.

## Contact

Questions about this policy can be sent to the address in the site footer.
